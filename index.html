@@ how it works @@

Three steps, about thirty seconds

No config file, no API keys to manage in your repo — the App handles auth once, at install time.

01

Install the App

Grant access to every repo or just the ones you pick. GitHub handles the permission screen.

02

Open a pull request

Push a branch and open a PR the way you normally would. The webhook fires automatically — nothing to trigger by hand.

03

Read the review

Inline comments land on the diff within seconds, each tagged by category and severity, with a short summary at the top.

@@ built for real pull requests @@

Not a demo — built around GitHub's actual constraints

Every behavior here exists because a naive version of it broke on a real PR first.

Services/ReviewService.java
+

Security-first prompting

Flags SQL injection, hardcoded credentials, and weak hashing before they reach main — and says nothing when a diff is genuinely clean, instead of inventing nitpicks.

+

Structured, schema-validated output

Every finding comes back as typed JSON, not free-form prose — so a review can never partially fail to parse.

util/DiffParser.java
+

Line-accurate comments

A unified-diff walker maps every finding to a real commentable line, so reviews never fail on GitHub's line-position constraint.

Controllers/WebhookController.java
+

Fast by design

Reviews run on a dedicated async thread pool, so the webhook responds within GitHub's timeout while the actual review keeps working in the background.
